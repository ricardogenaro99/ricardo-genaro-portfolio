## 🎨 Diseño & Arquitectura del Portafolio

El portafolio está construido con una estética **inmersiva de IDE / editor de código** que simula la experiencia de VS Code:

- **Barra de Pestañas de Archivos** (`EditorTabBar`) — Muestra los archivos abiertos con extensión real (`.md`, `.js`, `.json`) e icono vectorial correspondiente, activa la pestaña según la ruta actual.
- **Explorador de Archivos** (`Explorer`) — Panel lateral de directorios y archivos del portafolio, con concordancia 1-a-1 con las pestañas del editor.
- **Aislamiento de Contenido por Archivo** — Cada archivo del explorador muestra contenido completamente aislado e independiente al ser seleccionado, simulando abrir un archivo individual.
- **Scroll Reset por Ruta** — Al navegar entre secciones, el contenido del editor vuelve automáticamente al tope.
- **Responsividad Móvil** — En pantallas ≤ 830px, la barra de pestañas se oculta automáticamente para liberar espacio vertical. El layout cambia a flujo vertical para una navegación móvil nativa y cómoda.
- **Filtros Activos por Defecto** — En la sección de Proyectos, todos los filtros de tecnología se inicializan como activos, mostrando el portafolio completo al entrar.
